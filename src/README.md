# Source Navigation

This document is intended to provide context on how the website itself is generated and how to go about customizing as necessary.

## File Directory

> App.tsk - tba
> main.tsk - tba
> styles.css - used for consistence style/branding that is implemented globally
> > app - configs
> > content - various bits and pieces
> > features/admin - definitions for the admin-portal
> > layout - javascript that defines HTML references for overall layout
> > pages - more specific HTML breakdown for individual pages
> > styles - more global branding settings
