# Assets

The source package currently contains rendered PDF references only. The public site now uses CSS-generated framed panels, grid rails, and abstract video still placeholders inspired by the approved dark catalog preview. Replace those CSS-generated treatments with original production image or video assets when those files are available.

Recommended folders:

- `assets/brand/` for logo or brand-mark imagery.
- `assets/video-stills/` for preview thumbnails.
- `assets/backgrounds/` for frame, grid, or background treatments.
